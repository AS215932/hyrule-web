What an x402 VPS is

x402 turns HTTP 402 Payment Required into a real checkout. Hyrule Cloud answers a VM order with exact payment requirements. The client signs a USDC transfer on {{ chain_sentence }} and retries with a Payment-Signature header. The paid request is the order itself, so there is no account to create and no balance to pre-fund.

Prices and schemas are published in the x402 manifest and the OpenAPI document. The same model covers the paid network diagnostics: DNS, BGP, TLS, mail and port checks.

Agent flow
  1. 1 Read prices from https://cloud.hyrule.host/.well-known/x402.json.
  2. 2 POST the VM order and receive 402 Payment Required with exact requirements.
  3. 3 Sign the USDC authorization and retry with Payment-Signature.
  4. 4 Poll the returned status URL, then SSH to the VM over IPv6.
